# Expense Tracker App

A clean, responsive web application for managing your personal finances. Track income and expenses, monitor your budget, and maintain financial awareness with an intuitive interface.

## Features

- **Income & Expense Tracking**: Easily add and categorize financial transactions
- **Real-time Balance Calculation**: Automatic updates of total income, expenses, and net balance
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Clean Interface**: Simple and intuitive user experience
- **Transaction History**: View all your transactions in a clean, sortable table
- **Data Management**: Clear individual transactions or reset all data
